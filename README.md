# GTU BE Electrical Question Papers Archive

A permanent index of Gujarat Technological University (GTU) Bachelor of Engineering, Electrical Engineering (branch 09) old question papers: every subject code from the GTU syllabus archive, checked against every exam session on the official GTU paper server from Summer 2013 to Summer 2026.

**1569 papers found** for 204 of 273 subjects. Papers were checked on old26.gtu.ac.in using the official pattern uploads/{session}/BE/{code}.pdf; a paper counts only when the server returned a real PDF.

## Note

Subjects with no papers listed have no paper on the GTU server for any checked session: this includes MOOC and project subjects, and the newest subjects whose first exams have not been uploaded yet.
